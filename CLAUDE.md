# Claude Code rules for this repository

## Git is off-limits
Do not run git add, git commit, git push, git commit --amend, or any other git command. Not on your own initiative, not as a finishing touch, not as the natural next step. Your job ends when file edits are on disk and you have reported back. Marc handles all git operations himself.

## No commit trailers
Do not add Co-Authored-By, Signed-off-by, or any other trailer to commit messages. If you believe a commit would be appropriate, mention it in your report-back — do not execute it and do not draft a message.
